## About the project

FacePalm is an experimental clicker game designed to explore different areas of software development within a single application.

The project combines a native Android application written in Java, a backend for game logic and data management, and a web interface.

## Technologies and architecture

- **Android and Java:** mobile application development.
- **Spring Boot:** backend structure and REST APIs.
- **PostgreSQL:** relational data persistence.
- **HTML, CSS, and JavaScript:** web interface.

## Next steps

The roadmap includes implementing the click system, exploring smartphone hardware sensors, developing additional gameplay features, and integrating features such as authentication, synchronization, and a player leaderboard.

The project is under development. Its repository contains the code and the plan for future improvements.
