## Sobre o projeto

O FacePalm é um projeto experimental de jogo clicker desenvolvido como uma oportunidade de explorar diferentes áreas do desenvolvimento de software em uma única aplicação.

A proposta combina uma aplicação Android nativa com Java, um backend para gerenciar a lógica e os dados do jogo e uma interface web.

## Tecnologias e arquitetura

- **Android e Java:** desenvolvimento da aplicação móvel.
- **Spring Boot:** estrutura do backend e das APIs REST.
- **PostgreSQL:** persistência de dados relacionais.
- **HTML, CSS e JavaScript:** interface para a versão web.

## Próximas etapas

O planejamento do projeto inclui implementar o sistema de cliques, explorar o uso dos sensores físicos do smartphone, desenvolver funcionalidades adicionais e integrar recursos como autenticação, sincronização e classificação de jogadores.

O projeto está em desenvolvimento. O repositório contém o código e o planejamento de sua evolução.
